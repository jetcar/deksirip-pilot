# 比较案例与比较边界

> **翻译说明：** 本文由人工智能翻译，未经母语者审校。如遇歧义，以[英文版](comparative-analogs-en.md)为准。发现误译请提交 [issue](https://github.com/jetcar/deksirip-pilot/issues)。

以下中国案例展示的是单独的制度或试点方法，并不能证明 DEKSIRIP 整体模型
已经被实施。

| 提议要素 | 可观察到的案例 | 可以作出的判断 | 不能作出的判断 |
|---|---|---|---|
| 试点式规则改革 | 经济特区和自由贸易试验区 | 可以在有限区域先测试规则，再考虑推广 | 试点区域已经测试了公共剩余的民主分配 |
| 公共资产和地方收入 | 农村集体企业与集体分红 | 集体资产可以产生地方收入并向成员支付 | 这等同于所有居民的平等分红，或已经防止内部人控制 |
| 基本服务和差距降低 | 浙江共同富裕示范区 | 可以在较大范围协调公共服务和不平等指标 | 基本保障已经与就业和私人所有权分离 |
| 自然资源登记与治理 | 自然资源登记、使用权和收益管理改革 | 可以建立清查、所有权与使用权分离、收益和责任控制 | 居民已经直接管理全部资源组合 |
| 战略储备 | 国家和地方粮食、能源、医疗储备 | 关键投入的提前保障已经是独立制度 | 储备目标已经通过开放的居民参与决定 |
| 透明成本信息 | 价格、市场和试验区改革 | 价格和规则可以作为信号并在不同制度中测试 | 已经证明不以私人租金作为主要激励的协调方式 |

## 结论

最稳妥的说法是：中国已有分阶段试点、集体资产、公共服务和资源治理方面
的经验。研究问题不是重新发明每个要素，而是在预注册评估、透明度和退出
权的条件下，检验它们的有限组合。
