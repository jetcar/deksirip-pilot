# 关键概念与主要反对意见

> **翻译说明：** 本文由人工智能翻译，未经母语者审校。如遇歧义，以[英文版](definitions-and-objections-en.md)为准。发现误译请提交 [issue](https://github.com/jetcar/deksirip-pilot/issues)。

本文在讨论制度和技术之前，先固定关键术语的含义。

## 一、工作定义

| 术语 | 本提议中的含义 |
|---|---|
| **公共资源** | 其准入规则由公共或集体授权决定，而不是由一个私人所有者决定的资产或资源流。这不代表所有人可以无限使用。 |
| **基本物资** | 被承认为试点参与者权利的最低生活必需品数量，不是无限消费的承诺。 |
| **剩余** | 在满足基本义务、维护产能、储备和生态约束之后剩下的资源，必须同时按实体量和财务量计算。 |
| **社会分红** | 公共资产可分配结果的等额或预先约定份额，是对结果的权利，不是对资产的个人所有权。 |
| **透明度** | 能够核查数据来源、规则、计算、决定和结果，不等于公开所有个人信息。 |
| **参与** | 在法律、可用余额和既定程序内影响公共资源决定的能力，不等于每一次日常操作都必须投票。 |
| **成本信息** | 直接和间接投入、产能限制、稀缺性、机会成本以及重要外部损害；它用于辅助决定，不是自动产生公平价格的公式。 |
| **试点** | 有边界、有限期限、有限资源和权限、自愿参加、可比较并有停止权的实验。 |

## 二、主要反对意见

| 反对意见 | 模型回应 | 试点必须检验什么 |
|---|---|---|
| 人们会使用系统却不帮助维护 | 基本权利不取消贡献、照护和责任规则；这些规则必须与政治惩罚分开 | 是否出现参与不足，或互助增加 |
| 不可能获得所有资源的可靠信息 | 模型不要求完美信息，但要求公开数据质量和不确定性 | 报告资源与实际资源的差距是否缩小 |
| 多数人可能剥夺少数人的权利 | 基本权利和申诉不应取决于当前投票；决定受法律和程序约束 | 弱势群体是否受到保护，申诉是否有效 |
| 投票会变慢并使生产瘫痪 | 日常工作由拥有有限授权的执行者负责；集体决定主要涉及目标和重大变化 | 决定需要多少时间，产出是否受到影响 |
| 透明度会变成监视 | 公开的是汇总数据和证明，不是不必要的个人生活记录 | 能否在不暴露个人生活的情况下核查决定 |
| AI 会放大操纵 | AI 只是可解释、可审计的助手，没有投票和执行权限 | 使用 AI 后，人们是否更能发现错误、不确定性和替代方案 |
| 参与者会回到普通市场经济 | 外部经济仍然存在，退出权是设计的一部分，不是失败 | 参与者为何留下或退出，以及这带来什么变化 |
| 管理成本会过高 | 试点必须把管理时间、审计和支持都计算为成本 | 成本是否超过公共结果 |

## 三、主张边界

必须区分三个层次：

1. **价值判断：** 基本物资应当得到保障，公共资产不应产生私人租金。
2. **假设：** 透明地连接需求和资源会改善结果。
3. **事实：** 某个具体试点根据预先设定的指标测得了变化。

不能把前两个层次说成第三个层次。
