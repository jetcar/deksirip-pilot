# 联系中国研究者的计划

## 目标

获得对模型的学术批评，并了解哪些要素可以放在中国制度环境中研究。第一封
邮件不请求实施、资助或政治背书。

## 行动顺序

1. 填写作者姓名、所属机构或独立研究者身份以及工作邮箱。
2. 根据研究方向匹配度选择第一批三位收件人。
3. 根据每位研究者的研究或所在机构，增加一句个性化说明。
4. 用中文发送简短邮件，附上中文 PDF 和仓库链接。
5. 7–10 个工作日后只发送一次礼貌提醒。
6. 不群发、不使用密送，也不暗示项目已经可以立即实施。
7. 在联系记录中保存回复、批评意见和对方推荐的资料。

## 优先方向

### 第一批

- **收入分配与共同富裕：** 浙江大学共享与发展研究院。
- **公共财政与制度设计：** 清华大学经济管理学院经济系。
- **发展、公共财政与改革：** 北京大学国家发展研究院。

### 第二批

- **劳动、发展与共享保障：** 中国人民大学经济学院。
- **收入、社会政策与评估：** 中国人民大学共同富裕研究院及相关研究中心。

## 邮件组成

- 主题：“请求对地方经济试点提案进行学术评议”；
- 120–180 个中文词；
- 一段介绍模型；
- 一段说明为什么联系这位研究者；
- 三个具体的批评问题；
- 中文概念说明 PDF；
- 公共仓库链接；
- 作者姓名和联系方式。

## 发送前条件

只有填写以下字段后，才可以发送邮件：

```text
作者姓名：
所属机构或独立研究者身份：
电子邮箱：
可以接受回复的语言：
```

在这些字段填写前，材料已经可以审阅，但不能代表一个身份不明的作者发送。
