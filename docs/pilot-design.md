# Pilot Design

## Design principle

Start with the smallest unit that can operate a real budget, provide a defined
basic basket and publish reliable accounts. Do not begin with a national-scale
reform.

## Phases

### Phase 0 — feasibility and legal review

- identify the locality and institutional host;
- map assets, legal powers, suppliers and vulnerable groups;
- publish the proposed rules and invite criticism;
- define the evaluation protocol and stop conditions;
- obtain informed consent from participating residents and organizations.

### Phase 1 — information and services

- publish an asset register and monthly resource accounts;
- establish the basic-service basket;
- measure baseline prices, access, working time and household security;
- run the audit and grievance channels before introducing a dividend.

### Phase 2 — limited allocation pilot

- introduce a small social dividend from clearly identified common revenue;
- allow residents to support a limited set of projects;
- release project resources in reviewable tranches;
- operate strategic reserves with published targets and stock levels.

### Phase 3 — evaluation and decision

- compare outcomes with the baseline and matched localities;
- publish independent findings and anonymized data;
- continue, modify, pause or terminate the pilot according to pre-registered
  rules.

## Governance safeguards

- no permanent appointment for the executive operator;
- separate operating, auditing and adjudication functions;
- public conflict-of-interest declarations;
- protected whistleblowing and grievance channels;
- no loss of basic services as punishment for political disagreement;
- clear exit and appeal procedures.

## Minimum viable pilot

The first version should test only a defined basket of basic goods and a small
number of common projects. It should not claim to test every sector, advanced
monetary policy or national defense. A narrow failure is more informative than
an unmeasurable success claim.
