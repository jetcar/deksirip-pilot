# 给研究者的简短邀请

**主题：** 邀请评议地方经济试点提案

尊敬的研究者：

我准备了一份小规模、自愿参加、可逆的经济试点提案。它尝试结合基本保障、
公共资产可分配结果的一部分、透明的资源与成本信息、分阶段的项目支持、
战略储备和独立审计。

本提案不声称提出了新的经济意识形态，也不声称已有一套被证明的制度。它
提出的实践问题更有限：能否在保持自愿参加、退出权和可比较评估的条件下，
检验一些在中国及其他国家分别出现过的制度的有限组合？

希望得到以下四个方面的批评：

1. 经济假设是否成立；
2. 中国和国际上是否已有相关案例；
3. 试点面临哪些法律和制度限制；
4. 所提指标和比较组是否适合评估。

否定性的结论同样有价值。如果这一想法不可行，或把互不兼容的机制混在一
起，这种批评可以帮助缩小问题，或者放弃当前设计。

材料提供俄语、英语和中文版本。技术工具——资源登记、电子投票和 AI 助手——
放在附录中，并不是项目的出发目标。

此致

Vladimir Kruglov（弗拉基米尔·克鲁格洛夫）  
独立研究者，DEKSIRIP 项目
