# Outreach package

Материалы для первой академической рассылки по DEKSIRIP.

Публичные инструкции находятся в этой папке. Адресаты, персональные черновики
и журнал контактов хранятся локально в `outreach/private/` и исключены из Git.

## Порядок

1. Отправить письма 01–03 вручную с личного адреса.
2. Приложить китайский PDF из публичного репозитория или дать ссылку на него.
3. Не использовать массовую рассылку и скрытые копии.
4. Обновить `send-log.md` только после фактической отправки.
5. Один раз напомнить через 7–10 рабочих дней.

Публичный пакет: https://github.com/jetcar/deksirip-pilot
