Version 0.2 · 3 November 2026 · five pages per language.

Each PDF is a standalone reading packet: a plain-language model overview and
example, the pilot concept, questions for reviewers, two official sources with
limits of inference, and the author's contact. GitHub access is not required
to read or comment on the packet. These are research proposals, not evidence
that the full model has been tested or validated.
