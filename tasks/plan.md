# План подготовки предложения DEKSIRIP

## Цель

Подготовить понятное для исследователей предложение локального эксперимента:
сначала объяснить экономическую модель и проверяемую гипотезу, затем описать
границы пилота, доказательства, оценку и только после этого — технические
инструменты.

## Архитектурное решение

- Основной документ объясняет институты и причинную логику без технического
  жаргона.
- Техническая архитектура и спецификация остаются приложениями.
- Все ключевые материалы выпускаются на русском, английском и китайском.
- Предложение не утверждает готовность модели; цель первой стадии — получить
  аргументированную критику.
- Пилот ограничен, доброволен, обратим и сравним с базовой линией или контрольной
  территорией.

### Контрольная точка A

- [ ] Исследователь может пересказать модель без технических документов.
- [ ] Для каждого обещания указано, чем его измерять.
- [ ] Неясные или нормативные утверждения отмечены как гипотезы.

- [x] Задать принцип малого и обратимого эксперимента.

- [ ] Описать механизм согласия, выхода и защиты уязвимых групп.

### Фаза 4: технические приложения

- [ ] После утверждения концепции выбрать минимальный стек и сценарий демонстрации.

### Контрольная точка B

- [ ] Технические решения не подменяют экономическую гипотезу.
- [ ] Прототип можно остановить без потери права выхода и без необратимого

- [ ] Независимый проверяющий может воспроизвести ключевые расчёты.

### Фаза 5: внешняя критика

- [ ] Сформировать пакет для профессоров и исследовательских центров.
- [ ] Отдельно запросить критику концепции, права, измерений и технологий.
- [ ] Зафиксировать полученные возражения и изменения версии.

## Риски

| Риск | Реакция |
|---|---|
| Технические детали заслонят идею | держать архитектуру приложением |
| Модель окажется слишком нормативной | отделять ценности, гипотезы и измеряемые утверждения |
| Пилот будет слишком широким | ограничить корзину благ, активы и срок |
| Прозрачность превратится в слежку | разделить публичные агрегаты и персональные данные |
| Голосование парализует исполнение | сохранить профессиональный исполнительный мандат и аудит |
